# Decision: the agent kit (brain + hooks + AI employees)
_Last updated: 2026-10-08_

We run Claude Code in this repo as a small AI team. The patterns come from Professor Glitch (@pro.glitch, askglitch.com).

- **Markdown wiki, not RAG.** A store's knowledge fits in hundreds of pages. Reading a ~2k-token index plus 1–3 pages is cheaper and more reliable than a vector database, and it's versioned in git for free.
- **Hooks for rules, prompts for preferences.** A prompt line is a suggestion. A hook runs every time and can't be talked past. Safety (secrets, destructive commands) and "done means done" are hooks.
- **One job per employee: trigger, instructions, tools, brake.** Give each the least set of tools it needs, and gate anything public or irreversible behind a human "yes".
- **Memory has a write path.** `SessionStart` loads the index and journal, and `/wrap-up` writes durable learnings back.
